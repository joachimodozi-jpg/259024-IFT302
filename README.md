# Odozi Ifeanyichukwu Joachim — Personal Portfolio

A clean, minimal, and responsive personal portfolio website for **Odozi Ifeanyichukwu Joachim**.

The website is designed to showcase personal information, skills, projects, and contact details through a simple and classy interface.

---

## ✨ Features

- Clean and minimal design
- Fully responsive layout
- Personal hero section with profile artwork
- About Me section
- Skills section with animated skill bars
- Projects showcase
- Contact section
- Social media links
- Light/Dark mode toggle
- Responsive mobile navigation
- Smooth scrolling
- Scroll reveal animations
- Active navigation highlighting
- Automatic copyright year
- Theme preference saved using Local Storage

---

## 🛠️ Technologies Used

This project was built using:

- **HTML5** — Website structure and content
- **CSS3** — Styling, layout, animations, and responsiveness
- **JavaScript** — Interactivity and dynamic functionality
- **Google Fonts** — DM Sans and Playfair Display

No frameworks or libraries are required.
